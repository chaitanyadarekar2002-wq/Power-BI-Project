# 📊 Power BI Dashboard Project

## 📌 Overview

This project presents an interactive **Power BI dashboard** built to analyze data and generate meaningful insights. It helps users explore trends, track performance, and make data-driven decisions through visual storytelling.

---

## 🔍 Features

* 📈 Interactive visualizations (bar charts, line charts, KPIs)
* 🎯 Dynamic filtering using slicers
* 🔄 Data transformation using Power Query
* 🧠 Advanced calculations using DAX
* 🔗 Data modeling with relationships

---

## 📊 Insights

* Trend analysis over time
* Performance comparison across categories
* Key KPI tracking
* Detailed breakdown of metrics

---

## 🛠️ Tools & Technologies

* Power BI Desktop
* DAX (Data Analysis Expressions)
* Power Query
* Excel / CSV
